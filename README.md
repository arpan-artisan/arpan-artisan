## Featured Projects

### [QueryForge — Safety-First NL-to-SQL Agent](https://github.com/arpan-artisan/QueryForge)

A CLI-first data agent that translates natural-language questions into safe, validated PostgreSQL queries.

- Uses a structured **LangGraph workflow** for intent analysis, context building, SQL generation, validation, execution, and response assembly
- Applies deterministic intent policies and **AST-based SQL validation** before database access
- Executes queries through a restricted, read-only PostgreSQL role
- Supports bounded SQL repair, process-local conversation memory, local tracing, and optional Langfuse export
- Includes a **35-case evaluation suite** covering analytics correctness and safety policies

**Technology:** Python, LangGraph, PostgreSQL, SQLGlot, Langfuse, Docker, pytest

---

### [RAG Observer — Event-Driven PDF Intelligence](https://github.com/arpan-artisan/RAG-Prod)

An event-driven system for ingesting PDFs and answering grounded questions about their contents.

- Uses **Inngest** to coordinate document ingestion and question-answering workflows
- Serves workflow endpoints through FastAPI
- Stores and retrieves document embeddings through Qdrant
- Uses Gemini for embeddings and grounded answer generation
- Provides a Streamlit interface for document upload and conversational querying

**Technology:** Python, FastAPI, Inngest, Gemini, Qdrant, LlamaIndex, Streamlit

---

### [Medical Healthcare Assistant](https://github.com/arpan-artisan/End_to_end_medical_assistant)

A domain-focused RAG assistant that answers questions using medical reference documents.

- Uses biomedical embeddings to retrieve relevant medical context
- Generates structured responses using BioMistral-7B
- Stores document embeddings persistently with ChromaDB
- Provides a conversational Streamlit interface
- Includes medical disclaimers and grounded-response behavior

**Technology:** LangChain, ChromaDB, BioMistral-7B, MedEmbed, Hugging Face, Streamlit
